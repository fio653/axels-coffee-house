AXEL'S COFFEE HOUSE - WEBSITE PROJECT

CONTENTS
- index.html: Home page
- about.html: About page
- products.html: Menu page
- services.html: Services page
- contact.html: Contact page
- style.css: Shared design and responsive layout

HOW TO OPEN
1. Extract this ZIP file.
2. Keep all five HTML files and style.css together in the same folder.
3. Double-click index.html to open the website in your browser.
4. Use the navigation links at the top to visit all five pages.

EDITING WITH NOTEPAD
Right-click any .html or .css file, choose Open with > Notepad.
After editing, press Ctrl+S and refresh the browser.

NOTES
- This project uses HTML and CSS only; no JavaScript.
- The navigation links work between all five pages.
- The contact form uses a mailto action. It depends on an email app being configured and does not save messages to a server.
- Images and web fonts are loaded from external services, so an internet connection is needed for those assets.
- Business address, prices, phone number, and email are sample details for a fictional school project.
